# Experiência Prática IV - Algoritmos e Pensamento Computacional

Este repositório contém o desenvolvimento e a implementação do algoritmo de ordenação Bubble Sort em linguagem C, realizado para a disciplina de Algoritmos e Pensamento Computacional na Universidade Cruzeiro do Sul.

## 🚌 Cenário e Desafio
O objetivo do sistema é ordenar um vetor de 10 posições que armazena o tempo de deslocamento (em minutos) de 10 ônibus em um ponto de transporte municipal. O programa executa as seguintes etapas:
- Exibição dos dados brutos originais.
- Ordenação e exibição dos tempos em ordem crescente.
- Ordenação e exibição dos tempos em ordem decrescente.

## 🛠️ Tecnologias Utilizadas
- Linguagem C
- Visual Studio Code Web & GitHub
- OnlineGDB (para compilação e testes em tempo real)
